# GRPO Fine-Tuning: Qwen-2.5 on GSM8K

Данный проект посвящен дообучению языковой модели (Qwen-2.5-1.5B-Instruct) методам обучения с подкреплением, а именно алгоритмом **GRPO** (Group Relative Policy Optimization). 
Модель обучается решать математические задачи из датасета GSM8K, формируя цепочку рассуждений (Chain of Thought) внутри тегов `<think>` и выдавая финальный ответ в теге `<answer>`.

## 📁 Структура проекта

```text
diploma_work/
│
├── scr/                        # Модули с исходным кодом
│   ├── __init__.py             # Инициализация Python-пакета
│   ├── config.py               # Главный файл конфигурации (гиперпараметры, пути)
│   ├── dataset.py              # Загрузка датасета GSM8K и форматирование промптов
│   ├── model.py                # Инициализация базовой модели и настроек LoRA
│   └── rewards.py              # Функции наград (Reward Functions) для GRPO
│
├── .gitignore                  
├── requirements.txt            
└── train.py                    # Главный скрипт запуска процесса обучения
```

## 🚀 Инструкция по запуску

### 1. Подготовка окружения

Создание и активация виртуального окружения (на примере venv):
```bash
python -m venv venv
source venv/bin/activate  # Для Mac/Linux
# venv\Scripts\activate   # Для Windows
```

### 2. Установка зависимостей
Установите все необходимые библиотеки из файла конфигурации:
```bash
pip install -r requirements.txt
```

### 3. Настройка конфигурации (Опционально)
Все главные гиперпараметры обучения вынесены в файл `scr/config.py`. Перед запуском вы можете их изменить:

Также в файле `scr/rewards.py` можно настроить веса для системы наград.

### 4. Запуск обучения
Для старта процесса дообучения выполните команду:
```bash
python train.py
```

### 5. Отслеживание метрик (MLflow)
В проекте используется MLflow для логирования лоссов и наград. Чтобы посмотреть графики обучения в реальном времени, откройте новый терминал, активируйте окружение и запустите UI:
```bash
mlflow ui
```
После этого перейдите в браузере по ссылке, которую выдаст терминал.
